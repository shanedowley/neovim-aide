# Project Context

## Product Name

**Neovim-AIDE**

## Strapline

> A Neovim IDE
> Human-controlled. AI-assisted.

---

# Purpose

Neovim-AIDE is an AI-assisted software development environment built on
Neovim.

It helps developers understand, modify and maintain software while keeping
them responsible for every decision. AI augments the developer's capabilities;
it does not replace developer judgement.

---

# Vision

Neovim-AIDE demonstrates that AI can be integrated into a development
environment without sacrificing correctness, transparency or developer
control.

Every feature should reinforce the principle:

> The AI assists.
>
> The developer decides.

---

# Architecture

The project is organised as focused, loosely coupled modules.

New functionality should integrate with existing components where practical.
Architectural consistency is valued more highly than rapid feature growth.

Source code and technical documentation remain authoritative for implementation
and behaviour.

---

# Successful Contributions

A successful contribution leaves the project:

- simpler
- clearer
- correctly validated
- appropriately documented
- easier to maintain

Changes should move the project forward without weakening the qualities that
make Neovim-AIDE reliable and approachable.
